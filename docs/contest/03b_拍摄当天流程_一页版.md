# 演示视频拍摄当天流程（一页版 runbook）

> **怎么用**：打印这一页，按 ①→⑥ 走，每完成一项打勾。详细的分镜、字幕、按键语义在
> [`03_演示视频拍摄脚本.md`](03_演示视频拍摄脚本.md)，这里只写**顺序、时间、判据**。
> 全程目标：**半天拍完**（含架机与收工 4 小时），3 分钟成片。

---

## 时间预算（半天）

| 阶段 | 内容 | 预算 | 卡点 |
|---|---|---|---|
| ⓪ | 拍摄**前一天**：烧 bit、试跑状态脚本、清卡充电、打印清单 | 30 min | 不烧 bit 不许进现场 |
| ① | 架机与布光（两块板已上电） | 30 min | 12 条准备清单全勾 |
| ② | 通电自检 + 存证截图 | 10 min | 两片 `link=1 sync=1` |
| ③ | 实拍 S1–S10（含每镜 1–2 个 take） | 120 min | 每镜过 3 条判据才换镜 |
| ④ | 回看补拍 | 20 min | 只补不过的镜，不重拍全片 |
| ⑤ | 收工校验 + 素材双备份 | 10 min | 两片还在、素材两份 |
| ⑥ | 剪辑、字幕、导出、自检 | 90 min | 8 条导出自检全勾 |

## ⓪ 拍摄前一天（30 分钟，别省）

- [ ] 两片烧**最新** bit（C10，含底部中文字幕与计时器修复，且已写入配置 Flash）：`build\release\20261031_211735_A\WALL_A.bit` / `20261031_212015_B\WALL_B.bit`
      （烧前 `tools\probe_flash.ps1` 不带 `-Flash` 认 cable 号：**cable 0 = A、1 = B**，烧反了两块板会都变成 A）
- [ ] 跑一次 `tools\read_status.ps1 -Ports COM7,COM8 -Seconds 3`，确认能读、确认是 `starved-mask=0000` / `worst 0`
- [ ] **决定要不要固化配置**：拍摄中若要拔插排线反复试，先跑 `tools\persist_pair.ps1`（每片 ~2 min），
      否则断电 = 两块板变砖、要重烧。**这一步没做，就全程不能断电、不能碰插排**
- [ ] 相机电池 2 块满电、存储卡清空（≥64 GB）、笔记本能跑串口脚本
- [ ] 打印三样：本页、`03` 的 §2 分镜表、§4 字幕表
- [ ] 把 `03` 的 §3.2（开关位速查）单独截一张图发到手机上——现场比翻纸快

## ① 架机与布光（30 分钟，严格按这个顺序，别来回搬灯）

| 分钟 | 做什么 | 判据 |
|---|---|---|
| 0–5 | 上电，**保持供电**，插排贴胶带；等 10 s 让四张图上齐 | 4 个窗口出图、相册 `hi_ready=1` |
| 5–9 | 显示器设 **1:1 点对点**（关缩放/关自动亮度/关护眼/关屏保/关 HDR） | 640×480 画面四边不出黑框、字不发虚 |
| 9–13 | 关顶灯，只留两盏柔光（45° 侧上方，灯口朝板不朝屏） | 屏面无反光斑、板丝印可读 |
| 13–17 | 相机：**白平衡 5600K 手动 · 快门 1/50 · ISO 100 手动 · f/5.6 起**；关 DRO/自动亮度 | 直方图右端不顶格 |
| 17–21 | 三脚架 + 云台锁死；先装 **50 mm**（除了 S1 都用它） | 轻推机身画面不晃 |
| 21–25 | 构图：接缝落在画面**垂直中线 ±10 px**，屏占画面宽 70% | 监视器开网格线，缝对齐中线 |
| 25–28 | 清场：桌上只留两块板、两根 HDMI、一根 J1、一张 TF 卡 | 取景框里没有水杯/纸/反光物 |
| 28–30 | 三件套：场记纸、清空存储卡、手机静音 | 卡 ≥64 GB、电池 ≥80% |

## ② 通电自检（10 分钟，5 个判据）

- [ ] 两屏 HUD 都是 `LINK OK` + `SYNC OK`
- [ ] 串口读到 **A: link=1 sync=1 / tf phase=6 / sdram 0 错**，**B: hi_ready=1**
- [ ] 相册（SW4↑）能进能出，切页有淡变
- [ ] 拔一次 J1 再插回：`LINK LOST` → 3 帧恢复（**先试一次，确认兜底可用**）
- [ ] 截图存证：`shoot\evidence\status_A.png`、`status_B.png`（S9 用得上）

## ③ 实拍：按镜号 S1→S10（120 分钟）

**每镜的固定四步**：① 看监视器 HUD 正常 → ② 看直方图不溢出 → ③ 场记板写 `S04 take2` → ④ 开录、结尾停 1 s。

| 镜 | 预算 | 机位（拍完这镜要不要动机位） | 关键动作（详见 `03` §2） | 过镜判据 |
|---|---|---|---|---|
| S1 | 10 min | **100 mm 微距**，30 cm，垂直屏面 | 不按键，只拍缝 | 缝是**一条**线；网格线两侧对得上 |
| S2 | 8 min | **50 mm**，0.90 m（换镜头、退远） | 不动，0.5 s 上摇 4° 把板摇进画 | 两块板 + J1 排线都在画里 |
| S3 | 8 min | 50 mm，0.85 m（只调高度） | `KEY2` 让 UI 回来 | 4 个窗口齐全，id2 压在缝上 |
| S4 | 20 min | 50 mm，0.50 m（推近） | 基础层 → `KEY4` 选到 `SEL 3` → `KEY3` 锁 → `SW2↑` 进 MOVE → 左移 8 px → 按住 0.6 s 再 6 下 → 退回 → 解锁 | 边框跨缝是一条直线；`GX` 在跳、`OWN` A→B |
| S5 | 12 min | 50 mm，0.80 m | `SW2↓ SW3↑` 进 ZOOM → 放大 3 / 缩小 3 → 快放 / 快缩 → 回基础层 → 置顶 / 置底 | 内容始终 4:3 不变形；前后关系翻转 |
| S6 | 15 min | **前 6 s** 50 mm 0.60 m；**后 12 s 换 85 mm**，0.40 m | `SW1↑ SW2↑ SW3↑` 进 ADJUST → 亮度 +4 / −4 → 对比度 +3 / −3 → 结尾同按 1 s 复位 | `BRT`/`CON` 数值在跳；复位回 `80` |
| S7 | 15 min | 50 mm，0.90 m | `SW4↑` 进相册 → 等 0.3 s → `KEY4`×3（每次等 **≥0.8 s**）→ `KEY3` 回一张 → `SW4↓` 退出 | 1:1 跨缝居中、左右黑边；切页是先黑再亮 |
| S8 | 12 min | 50 mm，1.00 m，俯 10° | `SW1↓` → 手捏 J1 根部拔出 → 停 3 s → 对准 pin1 插回 → 停 3 s | `LINK LOST` 与 `FROZEN` 各停 ≥2 s；插回 3 帧恢复 |
| S9 | 6 min | **不拍屏**，电脑屏录 1920×1080 | 跑 `read_status.ps1` 录 10 s，另存两张 PNG | 两片字段都能看清 |
| S10 | 8 min | 50 mm，1.00 m | 回到 VIEW，`KEY2` 确保 UI 可见，手离开 | 画面定住 3 s，四个数字齐 |

**两个提速办法（任选）**

- **A（默认，稳）**：按 S1→S10 顺序拍。状态是连贯的：VIEW → 基础层 → ZOOM → ADJUST → 相册 → VIEW。
- **B（省架机，快 20 min）**：按**距离序**拍：`S1(30cm) → S4(0.5m) → S6(0.6→0.4m) → S5(0.8m) → S3(0.85m) → S2(0.9m) → S7(0.9m) → S8(1.0m) → S10(1.0m) → S9(屏录最后做)`。
  换序只多按几下开关，但少搬 6 次三脚架。**字幕和剪辑顺序仍按 S1–S10**。

## ④ 回看补拍（20 分钟）

逐镜回放，只问三条：**缝是一条线吗？关键 HUD 字看清了吗？结尾停够 1 s 了吗？** 不过就只补这一镜，
不要"重拍全片"。每镜至少留 take1 + take2，别只留一条（后期发现抖了还有备选）。

## ⑤ 收工（10 分钟）

- [ ] 跑 `tools\probe_flash.ps1`，**两片都还在**再拆线（拔过 J1 容易碰掉 JTAG/USB）
- [ ] 素材整目录拷到电脑 + 移动硬盘（**两份**），目录 `shoot\<日期>\S01..S10\`
- [ ] 把 ② 的两张状态帧截图一起归到 `shoot\<日期>\evidence\`
- [ ] 拍一张"现场工作照"（收工照，做 GitHub/答辩花絮用）

---

## ⑥ 剪辑到交片（90 分钟）

1. **导入**：按 `S01..S10` 分箱，选每条 take 的最好后半段。
2. **粗剪**：一条 V 轨按 S1–S10 铺，镜头间**硬切**，不加转场、不加片头黑场。
3. **掐时长**：每镜结尾留 1 s 静止；总长压到 **2:50–3:10**。
4. **字幕**：按 `03` §4 的 24 条表逐条打字，安全区距四边 ≥5%，**不压** HUD 左上文字块与 `BRT/CON` 行。
5. **音频**：只留同期声（合成器音 + 底噪，约 −18 dBFS），**不加背景音乐**、不加旁白。
6. **导出**：H.264 High、1920×1080/60p、**≥12 Mbps（目标 16）**、faststart、Rec.709 不加 LUT。
7. **命名**：`wall_demo_3min_1080p60_final.mp4` + 同名 `.srt`。
8. **自检**：总时长、缝无重影、`GX` 在动、`BRT/CON` 在跳、`LINK LOST` 停够 2 s、无旁白无音乐无水印、能拖进度条。

## 最可能翻车的 5 件事（30 秒处置）

| 现象 | 立刻怎么做 |
|---|---|
| 画面抖（以为又回到老问题） | 先看是不是**相机**在抖：三脚架没锁 / 手碰了机身。C9-R3 之后板子本身已确认不抖 |
| 相册连按没反应 | 停手等 **0.6 s** 再按；每次切页后默数"一" |
| 拔线插回不恢复 | 等 3 s；还不恢复就看是不是插偏一列；再不行断电重上电（**会丢配置，必须重烧**） |
| 屏上出现水波纹 | 平移 3–5 cm → 拉远换长焦 → 收到 f/8 → 斜 2° |
| 时间不够 | 砍 **S9**（证据镜头可用截图代替），再砍 S5 的置顶/置底；**S1/S4/S7/S8 一条都不能砍** |
