## 2. 配色

| 色 | 值 | 用途 | 字数限制 / 规则 |
|---|---|---|---|
| 深空蓝（主色） | `#0B1020` | 全幅底色；主视觉底衬；信息条加深版 `#070A14` | 不限（它是背景）。必须整幅铺满，**不要留白底** |
| 荧光青（强调） | `#00E5FF` | 标题左侧 4 px 竖线；`01–04` 编号；三个大数字；信息条分隔线；引导线 | **全幅 ≤ 40 字**。只做重点标注，绝不整段正文使用 |
| 橙（次强调） | `#FF6B2C` | 只两处：B 板标识（`WALL B` / 右屏）；接缝放大镜描边 | **全幅 ≤ 12 字**，面积 ≤ 画面 3% |
| 白 | `#FFFFFF` | 主标题、大数字、4 宫格小标题 | 单行 ≤ 22 字（再长必须换行） |
| 灰 | `#8A93A6` | 说明、图注、信息条次要行、网格 | 说明类全部用它；与底色对比度 ≈ 5.4:1，12 pt 以上可读 |

**三条用色硬规则**

1. 全幅只允许两处亮色：荧光青 + 橙。出现第三处亮色，一律压成灰。
2. 荧光青不做 12 pt 以下文字（细笔画在深底上会断），只做线、块、大数字。
3. 层次靠"大小 + 明度"，不靠加色：主标题白 → 数字荧光青 → 说明灰。三档封顶。

**印刷色域警告（必须处理）**

- `#00E5FF` 和 `#FF6B2C` 都超出 CMYK 色域，直接转色会明显变暗发灰（青会掉到 `#0AA8C4` 附近）。
- 印刷版把荧光青换成 **`#00C8DC`**、橙换成 **`#F26522`**（这两个值转 CMYK 损失最小）；电子版 PNG 仍用原值。
- `#0B1020` 这种大面积深色在数码印刷上易出条痕。交付时要求印厂"数码印刷 + 不打底"，先打一张 A4 小样看深色是否发花；若发花，把深空蓝提亮到 `#101828`。

## 4. 主视觉怎么做

占 `x 60–3448`、`y 511–1963`（**3388 × 1452 px**，比例 2.33:1）。

### 方案 A（推荐）：实物屏摄并排 + 接缝放大镜

**为什么选它**：评委会问"接缝真的对上了吗"。渲染图只能证明"设计上对齐"，**实拍才能证明"做出来了"**。这一张照片值一页 PPT。

拍摄清单（一次拍完，后面所有材料复用）：

1. 两块板并排，屏与屏贴紧（物理缝 ≤ 2 mm），板面正对镜头，镜头与屏面**垂直**，距离 1.2–1.5 m。
2. 关顶灯，只留屏自发光；手机专业模式：ISO 100、1/60 s、白平衡锁 5500 K、关 HDR、关美颜。
3. 三脚架 + 2 s 延时，连拍 10 张，挑**没有摩尔纹**的那张（摩尔纹靠前后移动 ±5 cm 消除）。
4. 必拍三张：
   - **T1 全景**：1280×480 桌面 + 4 个窗口（做主视觉）。
   - **T2 接缝特写**：怼到接缝，画面里要有**跨缝的那个窗口**（渐变窗口横跨 x 600–919，接缝在 640），窗口边框要连续、渐变不能断。
   - **T3 全屏相册**：一张照片居中跨缝那一帧（KEY4 切到第 2 张）。
5. 原图存 `wall/media/shots/`（新建），命名 `shot_T1.jpg` / `shot_T2.jpg` / `shot_T3.jpg`，**保留 EXIF 时间**（评委问拍摄时间时是证据）。

**版面拼法**（坐标已算好）：

```
y=511  ┌────────────────────────────────────────┐
       │ T1 全景 3388×1270（= 1280×480 × 2.647） │
       │  左屏 x 0–639        右屏 x 640–1279     │
       │              ╭─────╮ ← 放大镜 ⌀900      │
       │              │ T2  │   圆心 (1754,1146) │
       │              ╰─────╯   橙 6px 描边       │
y=1781 └────────────────────────────────────────┘
y=1800   图注 16pt 灰：实拍 · 日期 · 两块 HX4S20C 并排
y=1963  （区块结束）
```

- T1 满宽 3388，高度按 2.667 比例得 **1270 px**（`3388/1280×480 = 1270.5`），**不要拉伸**。
- 接缝在画布上的 x 坐标：`60 + 640×2.647 = 1754`。放大镜圆心就放 (1754, 1146)，直径 900 → `x 1304–2204, y 696–1596`。
- 圆内是 T2 的**同倍率**放大（不是重新构图），圆内右下角用 4 px 白线引出标注：`接缝 x=639 | x=640 相邻两像素`（20 pt 白）。
- 放大镜描边 `#FF6B2C` 6 px；圆外用 40% 黑遮罩压暗，让视线聚焦。
- 图注：`实拍 · 2026-10-31 · 两块 HX4S20C 并排`（16 pt 灰）。

### 方案 B：黑底金色线框系统框图

**用于**：照片拍不出来（反光/摩尔纹压不住）时的兜底；也适合"偏技术"的评委。

- 底 `#0B1020`，线框 1.5 px `#00E5FF`，节点填充 `#111827`，文字 20 pt 白。
- 结构：`TF卡 → BMP解码 → SDRAM图库 → 4bit链路 → B板SDRAM → 行缓存 → 像素函数`，下挂一行 `窗口表 4×64bit 每帧广播`。

## 5. 出图步骤

### 5.1 PowerPoint（最省事）

1. 新建空白文稿 → `设计` → `幻灯片大小` → `自定义` → 宽 **29.7 cm**、高 **42 cm**、纵向 → 确定 → 选"确保适合"。
2. `视图` 勾选 `标尺` + `网格线`；`网格设置` 间距 0.5 cm；排安全线时先临时关掉"对象与网格对齐"。
3. 右键空白处 → 设置背景格式 → 纯色 `#0B1020` → 应用到全部。
4. 画安全线（辅助，最后删）：矩形 `x 0.51 cm, y 0.51 cm, 宽 28.68 cm, 高 40.98 cm`，无填充、1 pt 洋红描边（60 px = 0.508 cm）。
5. 摆区块：PowerPoint 用 cm，**y_px × 0.00847 = cm**。例：`y 2027 px → 17.17 cm`。把 §1.1 的每个 y 值乘 0.00847 填进"位置 → 垂直位置"。
6. 文字：`插入` → `文本框` → 粘贴 §3 文案 → 直接设 pt 字号 → 行距用"多倍行距"填 1.05 / 1.55。
7. 图片：`插入` → `图片` → `图片格式` → `裁剪` → `填充`，再在"大小"里直接输 cm（3388 px → 28.70 cm，1270 px → 10.76 cm）。
8. 删掉第 4 步的洋红安全线。
9. 导出 PDF：`文件` → `导出` → `创建 PDF/XPS` → `选项` 勾 **"符合 ISO 19005-1 (PDF/A)"** → 发布。
10. 导出 300 dpi PNG（PPT 默认只有 96/150 dpi，先改注册表顶到 300，改完**重启 PowerPoint**）：

```powershell
New-ItemProperty -Path "HKCU:\Software\Microsoft\Office\16.0\PowerPoint\Options" -Name ExportBitmapResolution -PropertyType DWord -Value 300 -Force
```

然后 `文件` → `导出` → `更改文件类型` → `PNG` → `另存为` → "仅当前幻灯片"。

### 5.2 Figma / Canva

**Figma**（要做多版本时用）：

1. `F` 画 Frame，右侧宽 **3508**、高 **4961**（Figma 只有 px，§3 的 pt × 4.1667 得 px）。
2. `Layout grid` → Columns 12 / Margin 60 / Gutter 64，一眼看出有没有出安全线。
3. 导出：选中 Frame → `Export` → PNG 1x → 得到 3508×4961；PDF 用 `File` → `Export frames to PDF`（矢量文字）。

**Canva**：

1. `创建设计` → `自定义大小` → 29.7 × 42 cm。
2. **免费版导出的 PNG 只有约 96 dpi（≈1123×1587 px），达不到 300 dpi**。要用 Canva 就必须开 Pro 用"下载 → PNG → 3×"，否则改用 PPT 或 Figma。
3. Canva 的"PDF 印刷"会自动加 3 mm 出血并转 CMYK，这点比 PPT 省事。

### 5.3 印刷交付

- 交两个文件：`poster_A3_print.pdf`（CMYK + 3 mm 出血 + 裁切线）+ `poster_A3_300dpi.png`（RGB，官网/公众号用）。
- 出血做法：PPT 导出的 PDF 没有出血 → 在画布四边外各加 36 px 底色矩形再导出；或交稿时注明"深色底请自行扩边 3 mm"。
- CMYK 转换让印厂用 **ISO Coated v2**，并要求**先出 A4 数码样**，确认深色不发花、荧光青没变脏。
- 纸张：**250 g 哑粉纸 + 哑膜**（深色不反光）。不要用铜版纸亮膜——展板灯一照全反光，3 米外看不见字。
- 数量：现场 2 张（1 张贴、1 张备用），另加 1 张 A4 缩样给评委翻阅。
