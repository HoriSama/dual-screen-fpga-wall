## 1. 作品简介（多字数版本，按平台字数上限挑一个）

### 版本 A：一句话（≤ 40 字，用于列表页/摘要行）

```
两块安路 FPGA 各带一块屏拼成 1280×480 桌面，窗口可跨屏拖动、逐像素无缝。
```

### 版本 B：100 字版

```
两块安路 HX4S20C 开发板各驱动一块 640×480 HDMI 屏，拼成 1280×480 桌面，4 个窗口可用按键跨屏拖动且接缝逐像素无缝。作品不做帧缓存，每个像素由窗口表现算，因此接缝一致性由架构保证；A 板每帧把窗口表整份广播给 B 板，拔线各自降级、插回三帧自愈。两片 LUT 占用 67%/44%，零时序违例。
```

### 版本 C：300 字版（推荐，多数平台够用）

```
本作品用两块安路 HX4S20C 开发板（FPGA：EG4S20BG256）各驱动一块 640×480 HDMI 显示屏，并排拼成一块逻辑上 1280×480 的桌面。桌面上有 4 个监控窗口，可用板载按键把窗口从左边板拖到右边板，跨越两屏接缝时逐像素无缝、无错位无撕裂。
作品最核心的决定是不做帧缓存：每个像素都是窗口表与坐标的纯函数 f(x,y)，两块板共用同一份逻辑与同一份表快照，因此接缝两侧对同一世界坐标必然算出逐位相同的像素。A 板是窗口表唯一写者，每帧把 4 条 64 bit 记录整份广播给 B 板，B 板只显示不决策。图像来自 A 板 TF 卡中的 BMP，缩略图与全分辨率图切成 16 字块在 4 bit 链路上无应答循环推送，一轮 83,712 块约 1 秒，丢块自动补齐。相册模式把整面墙变成一张照片的实际像素，1:1 跨接缝显示。
A 板占 13,811 LUT（70.46%）、B 板 9,331 LUT（47.61%），25 MHz 与 150 MHz 均零时序违例，24 个 testbench 全通过，跨接缝逐像素比对 614,400 像素 0 差异。拔线显示 LINK LOST 并各自降级，插回三帧内自动恢复。
```

### 版本 D：500 字版（若平台简介栏较长，在版本 C 后接这段）

```
系统还实现了等比缩放（4 bit DDA 采样）、图层置顶置底、亮度与对比度实时调节并在画面上叠加 OSD 数值、轮播与切页的 16 帧淡入淡出、HUD 字幕（节点号、选中窗口、全局坐标、链路与同步状态），以及背景音乐双通路：A 板从 TF 卡读取 48 kHz/16 bit 立体声 WAV 循环播放，卡上没有可用 WAV 时自动回落到片上合成器，不会静音。
为了让"看不见的东西"可测，每块板以 34 字节/帧、10 帧/秒从 UART 输出状态帧，内容包括链路、帧同步、视频锁定、发送器重试计数、窗口表关键字段、TF 装载器阶段与错误码、SDRAM 自检结果、相册页码与拷贝就绪、行缓冲读口迟滞计数与音频状态；两块板都能独立读出，不接显示器也能判断系统状态。
本作品对应的赛题扩展要求完成情况：图层叠加与字幕（HUD/OSD、以及**跨两屏连续的底部中文滚动字幕**：16×16 字模、60 px/s、滚动相位由 A 板广播、长按 KEY2 开关）、图片轮播与转场（淡入淡出）、图片缩放适配（等比 DDA）、实时参数调节与 OSD（亮度/对比度）、音频可视化（电平条与音乐双通路）均有实现；此外用两块同款 FPGA 板卡构建主从结构、通过自定义链路部署不同功能模块，正是赛题所鼓励的多板结构。
```

## 3. 三分钟讲什么（若现场只有口头介绍）

1. **一句话**：两块板拼成一块屏，窗口能拖过去，接缝没有缝。
2. **一个反常识**：我们**没有帧缓存**——每个像素是算出来的，所以接缝不会错。
3. **三个数字**：LUT 70.46% / 0 时序违例 / 接缝 614,400 像素 0 差异。
4. **一个结构**：A 是唯一写者，每帧把表整份广播给 B，B 只显示不决策。
5. **一个健壮性**：拔线各自降级、插回三帧恢复；图片丢块下一轮自动补齐。
