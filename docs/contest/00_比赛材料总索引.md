## 3. 数字口径（唯一真相，改数只改这里）

所有材料里的数字必须一致，出处是 `build/td_A|B/*.rpt` 与 `build/release/`：

> 改完文档后要重新生成：`01_技术文档.md` → 跑 `python _md2docx.py`（生成 docx）；
> 插图 → `_gen_figs.py`；海报 → `_gen_poster.py`（改完 `_gen_poster.py` 里的实拍图路径再跑）。
> 三个脚本都在本目录，`.gitignore` 已经把它们排除在仓库外。

| 项 | A 板 | B 板 |
|---|---|---|
| LUT | **13,811 / 19,600 = 70.46%** | **9,331 / 19,600 = 47.61%** |
| REG | 8,214 | 6,176 |
| BRAM / DSP | 31 / 64 · 14 / 29 | 31 / 64 · 13 / 29 |
| 25 MHz Setup WNS | **+0.557 ns**（Fmax 25.354） | **+0.347 ns**（Fmax 25.219） |
| 150 MHz Setup WNS | **+0.353 ns**（Fmax 158.4） | **+0.185 ns**（Fmax 154.3） |
| 违例 | 0 | 0 |

其余固定数字：接缝 **614,400 像素 0 差异**、图片分发 **8 区域 / 83,712 块 / 轮**、
SDRAM **2,097,152 字全用满**、RTL **31 文件 8,332 行**、TB **35 文件 4,840 行（回归 24 个全 PASS）**、
状态帧 **34 B @115200**、链路 **4 bit / 6.25 MHz / CRC8**、上电 **~10 s 两屏齐**。

**C10（2026-10-31 21:2x，已上板 + 已写入两片配置 Flash）**：新增**底部中文滚动字幕**（16×16 字模、60 px/s、\因设备调试问题，今日博物馆暂停营业，\、长按 KEY2 开关、相册模式隐藏、**跨两屏连续**）；同期修掉两个只有上板才暴露的 bug（字幕误用局部坐标 → 两屏各放一份；HUD 计时器因上电复位缺失而从残值起数 → 现在加载完成才开始计时）。**这两件事要写进 01/03/08**，见本文件 §2 的材料状态表。

**抖动问题已闭环（C9-R3，2026-10-31 18:4x 操作员确认）**：
A 板行缓冲饥饿掩码 `0100`→`0000`、4 秒内最差帧 `13`→`0`；跨缝窗口 burst 从 192 字截到 45 字，
A 每行 576→429 字（−26%）。**RTL 从这一刻起冻结**，继续写材料不需要再碰 RTL。

> ⚠ 上表这 6 个数出自 `build/td_A|B` 的最新构建（`20261031_211735_A` / `20261031_212015_B`）。
> **如果之后又重建，请再核一遍**（`02`、`03`、`04`、`08`、海报里都引用了它们）。
> TD 的布局对网表变化极敏感，同一份 150 MHz 域的余量曾在 +0.011↔+0.633 之间跳（C10 期间就亲眼见过一次），别沿用上次的数。

## 5. 我替你做的 3 个判断（不同意就说）

1. **技术文档里只出现队伍号、队名、队员、指导老师，不出现学校名。** 依据是模板第一行
   "不要出现任何涉及学校名称等内容"。报名信息里该填的学校照填，两回事。
2. **全文不写"实时监控 / AI 识别 / 摄像头 / 以太网"。** 实际图像源是 TF 卡里的 BMP，
   视频源与显示节点是解耦设计的；写"解耦"比写"实时"安全，也不会被追问。
3. **已知欠账照实写**：卡上没有 `MUSIC.WAV`（现在是片上合成器）、两片 JTAG 临时配置、
   相册固定 4 张、不做音视频时间戳对齐。这几条都写进了文档的"局限"和答辩 Q&A 的"诚实答法"里
   ——评委问到时照着答，比被拆穿好。

## 6. 一处必须知道的订正

你在 `docs/12_handover_contest.md` §3 里的开关表有一格是 **MOVE 的编码**被写成了基础层：
板上实际是 **基础层 = SW1↑ SW2↓ SW3↓**、**MOVE = SW2↑ SW3↓（需先 KEY3 锁定）**，
依据 `rtl/wall_input.v` 的 `adj_mode / move_mode / zoom_mode` 解码。视频脚本里已按实际解码
给了速查表并保留原话作对照——**现场照修正后的那张表按**，否则按住 KEY4 会变成移动窗口。
